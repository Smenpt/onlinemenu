# Листва — меню и заказы по QR-коду

Гости заказывают с телефона по QR-коду на столике, персонал ведёт заказы, меню и кассу в админ-панели.

## Запуск

Нужен Node.js 22.13 или новее.

```powershell
.\start.ps1
```

Если Windows запрещает запуск скриптов:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

При первом запуске сервер покажет пароль администратора и сохранит его в файле `.env`.

| Страница | Адрес |
|---|---|
| Меню | `http://localhost:3000` |
| Админ-панель | `http://localhost:3000/admin` |

Телефоны должны быть в той же сети. Адрес для них сервер выводит при запуске.

## Перед открытием кафе

1. Войдите в админ-панель и проверьте меню.
2. Откройте вкладку «QR-коды» и убедитесь, что адрес в ней открывается с телефона. Если нет, укажите `PUBLIC_URL` в `.env`.
3. Напечатайте коды и разместите на столиках.

Без QR-кода гость может смотреть меню, но не может заказать: номер столика защищён подписью. Заказ за гостя можно ввести во вкладке «Заказы». Вне рабочих часов гостевые заказы не принимаются.

Лучше закрепить за компьютером постоянный IP-адрес в настройках роутера. Если адрес сменится, напечатанные коды перестанут открываться.

## Настройки

Все настройки лежат в `.env`, их описание есть в `.env.example`: пароль, число столиков, часы работы, порт, адрес для QR-кодов.

## Данные и резервные копии

- `data/cafe.db` — база SQLite: меню, заказы, сессии.
- `data/uploads/` — фото блюд.
- `backups/` — копии базы: при запуске и каждый час. Хранятся за последние 14 дней.
- `backups/legacy/` — старые `menu.json` и `orders.json`, перенесённые в базу.

Копии лежат на том же диске, поэтому время от времени сохраняйте папку `backups/` на флешку или в облако.

Чтобы восстановить базу, остановите сервер, замените `data/cafe.db` нужной копией из `backups/`, удалите рядом файлы `cafe.db-wal` и `cafe.db-shm` и запустите сервер снова.

## Разработка

```powershell
npm test
```

| Папка | Содержимое |
|---|---|
| `src/` | сервер: маршруты (`app.js`), база (`store.js`), вход, проверка данных, фото, копии |
| `public/js/` | гостевая страница, `admin/` — вкладки админ-панели, `shared.js` — общие функции |
| `test/` | тесты |
